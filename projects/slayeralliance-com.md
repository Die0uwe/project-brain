# slayeralliance.com

## Doel
Website van de Slayer Alliance (WoW-gilde en Discord-community, Discord-invite staat in de README-footers van de brain). Draait op WordPress met de [slayer-suite](slayer-suite.md)-plugin.

## Bekend
- WordPress + Blizzard EU API (zie slayer-suite).
- De brain-viewer noemt het als optie voor hosting (web/README.md, "Optie B: PHP op slayeralliance.com").

## Openstaande punten
Hosting, WordPress-/PHP-versie, thema en actieve plugins naast de suite: onbekend/te verifiëren. Het is niet bekend of Blueprint CMS (zie [blueprint-cms](blueprint-cms.md)) hier ooit het WordPress-systeem vervangt.
